IndTrace — Industrial Traceability & Production-Monitoring Platform

Traceability Industry 4.0 .NET 10 Real-Time Systems 2025–2026

Architected and directed development of IndTrace, a multi-tenant industrial traceability and production-monitoring platform at Exxerpro, with Valeo Special Products as its main user — evolved from a bespoke traceability system originally built for Valeo into a reusable platform architecture for tracking parts, cycles, and production events across PLC-connected manufacturing lines.

Scope of Work

  • Real-time data capture from PLCs across production lines, tracking machines, cycles, defects, and routing rules.
  • Multi-tenant architecture, allowing the platform to serve more than one manufacturing operation from a single codebase.
  • OEE (Overall Equipment Effectiveness) dashboards, production-line monitoring, and a diagnostic log analyzer.
  • Built around a deliberate design principle: the system tracks and validates that a part's arrival at a station is legal per its routing — it does not command or control the line itself.

Architecture

Built on a hexagonal .NET foundation with an event-driven PLC gateway feeding real-time production data into the platform, keeping the tracking layer strictly separate from line control — the system observes and validates, it never issues commands to equipment.

Technology

  • .NET 10 / C#, hexagonal / clean architecture
  • Blazor (MudBlazor), SignalR for real-time updates
  • SQL Server
  • xUnit
