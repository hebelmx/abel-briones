Multi-Line Traceability System — Automotive Lighting Assembly

Traceability Industry 4.0 Valeo 2023

Developed and deployed an integrated traceability system across three assembly lines — CHMSL Q5, Bumper Lamp, and Spoiler — for Valeo Special Products, capturing component genealogy in real time from Siemens S7-1200 PLCs and generating production and quality reports.

Scope of Work

  • Network cabling and canalization for an Ethernet backbone across all three lines.
  • Server and node configuration; code-reader and label-printer mounting hardware.
  • PLC/HMI programming for real-time data capture.
  • FAT/SAT and operator training.

Architecture

Each line's PLC pushes component and process data over a dedicated Ethernet backbone into a central traceability server, which flags out-of-spec parameters in real time and generates scrap and cycle-time reports.

Technology

  • Siemens S7-1200
  • Ethernet networking
  • Barcode/label-printing hardware, SQL-based reporting
