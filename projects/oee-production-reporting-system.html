Multi-Machine OEE Data Collection & Reporting Platform

Software & AI VB.NET SQL Server Steel / Wire Products

DeAcero's galvanized welded-mesh production had no OEE visibility across its 6 mesh-weaving machines. I designed and built a full VB.NET application suite backed by a central SQL Server database that talks to each machine's PLC, captures piece counts, cycle times, downtime and operator logins, and serves live per-machine OEE dashboards.

Scope of Work

  • VB.NET applications communicating directly with each machine's PLC.
  • A central SQL Server database for production, downtime, maintenance and operator data.
  • A full application suite: Catálogos (catalog admin), Ideas (improvement suggestions), Mantenimiento (maintenance scheduling), Monitor (diagnostics), Paros (downtime logging), Publisher (over-the-air app updates), Producción (production scheduling), Raw Material, Main (live operator HMI), Reports (auto-emailed), and Turnos (shift scheduling).
  • Live OEE dashboards per machine — availability, performance, quality and overall OEE %.

Architecture

Each of the 6 machines has its own PLC+PC pair feeding a central SQL Server database, which drives both real-time dashboards on the plant floor and scheduled, automatically emailed reports to management.

Technology

  • VB.NET desktop applications
  • Microsoft SQL Server
  • PLC-to-PC communication, web/desktop dashboards
